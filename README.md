## 📝 Prompt Engineering Tool  

A **web-based prompt engineering tool** that enables users to create, refine, and store AI prompts directly in browser local storage.  

## ✨ Features  
- **AI-Powered Suggestions** – Integrated with **LLaMA 3.1 70B Instruct Lite** for intelligent prompt generation.  
- **Persistent Storage** – Saves prompts in **browser local storage** for quick access.  
- **Modern Tech Stack** – Built with **React, Flask, and LangChain** for a seamless frontend-backend experience.  
- **Scalability & Deployment** – Hosted on **Azure**, ensuring smooth performance.  

## 📂 Tech Stack  
- **Frontend:** React  
- **Backend:** Flask  
- **AI Integration:** LangChain, LLaMA 3.1 70B Instruct Lite  
- **Storage:** Browser Local Storage  
- **Hosting:** Azure
